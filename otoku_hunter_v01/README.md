# お得ハンター v0.1

**目的**：無料懸賞・サンプル・ポイントなどの「候補」を自動収集して、あとで自分で確認・応募する個人用ツール。費用を増やさず、小さく検証する。

## 現段階でできること

- iPhone / PC 向けの案件一覧画面、検索、カテゴリーと状態の絞り込み
- 公開 RSS の見出しから、キーワードに該当する**未確認候補**を収集。詳細条件は自動確認しない
- 公開記事リンクを開く。回答・応募・ログインは**自分で**実施する
- 「あとで見る」「応募済み」「獲得済み」「除外」をローカルに保存
- 獲得済みポイントの実績管理、手動で案件追加、バックアップ JSON 出力・読込
- GitHub Actions で毎日自動収集（実行遅延の可能性あり）

## 初回利用（無料）

1. GitHub で **public repository** を新規作成（例 `otoku-hunter`）。**public にしたものは世界中から閲覧可能**。ユーザー名、メール、パスワード、住所を絶対に入れない。
2. `HUNTER` 直下の `otoku_hunter_v01/` と `.github/workflows/collect.yml` を、階層を保ったままリポジトリの既定ブランチに配置する。個人のバックアップファイルはアップロードしない。
3. **Settings > Pages > Build and deployment > Source** で **GitHub Actions** を選ぶ。
4. **Actions > Collect and publish candidates > Run workflow** で既定ブランチを選び、初回収集と公開を実行する。収集ログで件数を確認する。取得に成功して該当見出しがゼロなら、空の一覧も正常。
5. 実行結果の **deploy** に表示されるURLを、WindowsのブラウザとiPhoneのSafariで開く。「最終収集」の日時と候補一覧を確認する。

公開ページに含まれるのは `index.html` と `data/leads.json`。収集先がすべて取得に失敗した場合は実行結果を失敗とし、直前の収集データと公開ページを維持する。

`index.html` を直接開くこともできるが、ローカルファイルではブラウザの `fetch()` 制限で自動収集 JSON を読めないことがある。その場合は手動追加・記録機能だけ使用可能。

## 制約・安全上の注意

- 情報収集元は `sources.json` に明示。現時点は PR TIMES の公開 RSS 1本。公式サイトのRSSへのリンクから候補見出しを取得するだけ。将来、個々の情報源の利用条件を確認して拡張する。
- **キーワードが入った見出しを候補として並べるだけ**。案件が無料・有効・応募可能である保証はない。対象外の広告や宣伝も混ざる。ポイント額、締切、当選確率も推定しない。
- 広告視聴・クリックの自動化、アンケートのAI回答、CAPTCHA回避、アカウント作成、自動応募はしない。
- ポイント・氏名・住所などはGitHubに公開しない。状態と獲得履歴は端末のブラウザ `localStorage` に記録され、**PCとスマホでは同期しない**。状態を付けた案件は収集一覧の400件から外れてもブラウザに残る。端末を変える際は記録を保存・読込で移行する。読み込むと移行先の記録を上書きする。ブラウザのデータ消去で消える場合がある。
- データ収集はGitHub Actionsの無料枠・スケジュール・アクセス制限に依存。無償運用が続く保証はない。勝手に有料プランに移行する仕組みは入っていない。
- まずは少量の候補を目視で検証して、本当に有用な収集先が見つかってから機能を増やすのがおすすめ。

## フィードの追加

`sources.json` に RSS の名称とURLを1件ずつ追記する。**提供元が公開していて、自動取得を認める範囲のみ**を使用する。アンケートサイトなどログイン後ページは扱わない。

## データの更新

毎日日本時間07:17ごろ（保証なし）。GitHub Actionsから手動実行もできる。重複候補はURLで除去し、最大400件保持。

## 開発者向け

Python 3.12 標準ライブラリのみ。`HUNTER` 直下で `python otoku_hunter_v01/scripts/collect.py` を実行するとRSSから取得する。静的HTML/JSのためビルド不要。

Windowsで公開前に確認するには、`HUNTER` 直下で `python -m http.server 8000 --bind 127.0.0.1 --directory otoku_hunter_v01` を実行し、ブラウザで `http://127.0.0.1:8000/` を開く。終了するときはターミナルで Ctrl+C を押す。
